# Logo

Drop the logo file(s) in this folder — any of these work:

- SVG (best — scales cleanly, use if available)
- PNG with transparent background (next best)
- JPG (fine as a fallback)

If you have multiple versions (e.g. full color, white/reversed for dark backgrounds, icon-only/favicon source), drop them all in here with clear names (e.g. `logo-full-color.svg`, `logo-white.svg`, `icon.svg`). When the Astro project gets scaffolded, these get moved into `src/assets/` (optimized, imported in components) and/or `public/` (for the favicon and any place we need a raw static URL).
